# Returns and RMA Handling

A return moves freight from the original consignee back to the original shipper,
or to a designated returns facility.

To open an RMA, the shipper provides the original PRO number, a reason code
(damaged, refused, wrong item, or overage), and the return destination. Meridian
issues an RMA number and a return label within one business day.

Returns are billed at the standard rate for the return lane. Original outbound
charges are not refunded. A return is not a claim: a customer seeking
compensation for damaged freight must file a claim separately under the claims
policy, and opening an RMA does not pause the 21-day claim window.

Refused shipments (reason code: refused) are held at the delivering terminal for
5 business days awaiting return instruction, after which they move to the returns
facility automatically and begin accruing storage.
